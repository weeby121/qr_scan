# **App Name**: Cardify

## Core Features:

- Data Input Form: Input form for personal and contact details including name, designation, phone numbers, email, address and website.
- Real-Time Preview: Real-time card preview that dynamically updates as the user fills out the form, showing how the digital visiting card will look.
- QR Code Generation: Generation of a unique QR code that links directly to the user's digital visiting card, which will be hosted on cardify.
- Download and Sharing: Options to download the generated QR code as an image file for printing or sharing, and generate the hyperlink to their visiting card.

## Style Guidelines:

- Primary color: A modern blue (#2962FF) for a professional and trustworthy look.
- Background color: Light gray (#F5F7FA) to provide a clean and neutral backdrop, focusing attention on the card content.
- Accent color: A slightly darker gray (#7987A1) for text and interactive elements, ensuring readability and usability.
- Body and headline font: 'Inter', a grotesque-style sans-serif font known for its clean, modern appearance, is suitable for both headlines and body text.
- Use clean, minimalist icons for contact details (phone, email, website, address).
- Maintain a clean and structured layout for the digital visiting card, ensuring information is easily accessible and readable.
